一个**双击就能打开**的本地量化交易平台。不用装数据库、不用买数据、不用注册任何账号。

**核心工作流：在【策略】页配好策略 → 点【部署】确认一次 → 之后引擎按规则自动下单。**

把这个文件夹放到你想要的位置，不需要 `git clone`，也不需要联网安装任何东西。

```bash
# Windows：双击 启动量化平台.bat，浏览器自动打开 http://127.0.0.1:8899/
python -m app.main      # 或者用命令行启动（Mac / Linux 用这条）
```

## 它是什么

市面上多数"量化平台"要么是云端 SaaS（数据在别人机器上、按年收费），要么是重型框架
（Python 环境、依赖几十个包、动辄跑不起来）。这个项目的取舍正好相反：

| 取舍 | 说明 |
|---|---|
| **零第三方依赖** | 只用 Python 标准库，没有 numpy / pandas / torch。`pip install` 一步都不用做 |
| **本地单机** | 内置 `http.server` 起的网页界面，数据全在你自己机器的 SQLite 里，不联网也能回测 |
| **开箱即用** | 双击 `.bat` 就启动，不需要 DSN、不需要 API Key、不需要账号 |
| **真实到能亏钱的细节** | T+1、涨跌停板买不进卖不掉、佣金最低 5 元、印花税、过户费、滑点、成交量参与率、停牌顺延 |

代码规模：**约 2 万行 Python + 4 千行前端**，14 个策略、130 个因子。

## 功能一览

* **行情**：东方财富 / 腾讯 / 新浪（免费公开接口，多源熔断与自动降级，keep-alive 连接池）
* **选股**：一次扫描全市场 5923 只，11 个主流选股模板，一键把结果变成策略
* **因子实验室**：130 个因子（65 个 Alpha101 + 动量/波动/量价/形态/无监督学习），IC、分层收益、全因子扫描、行业中性化
* **回测**：真实撮合约束（T+1、涨跌停、停牌、参与率上限），无未来函数校验，Walk-forward 样本外验证，收益归因
* **组合优化**：等权 / 最小方差 / 风险平价 / 最大夏普 / 因子加权，支持行业中性、换手率与流动性约束
* **交易**：模拟盘（默认，20 万虚拟资金） / 同花顺(easytrader) / QMT 迅投
* **风控**：单只仓位上限、单笔金额上限、每日下单次数、当日亏损熔断、黑名单、ST 过滤、一键急停清仓
* **数据质量**：除权除息脏数据自动检测与前复权（实测把 −41.82% 的假跳空修正为 −14.72%）
* **基本面增强**（可选，断网自动降级）：PE/PB 分位、申万三级行业、分红送配方案

## 三、新手三步上手（建议照做）

### 第 1 步：先回测，别急着交易

1. 打开 **回测** 页
2. 策略类型选「双均线交叉」，股票池填 `000001.SZ,600036.SH,510300.SH`
   （注意：**别一上来就回测贵州茅台这类上千元一股的股票**，买 1 手就要十几万，很容易一笔都成交不了）
3. 开始日期选一年前，初始资金 100000，点【开始回测】
4. 重点看这四个数：**年化收益、最大回撤、夏普比率、对比沪深300**
   * 回撤比收益更重要。回撤 40% 意味着你要能忍受本金腰斩。
   * **跑不赢沪深300 的策略，别拿去实盘。**

### 第 2 步：在模拟盘跑

1. 打开 **策略** 页，参数照抄你回测时用的
2. 股票池填好、运行方式选「自动下单」，点【保存策略】
3. 在策略列表里点【启用】
4. 回到顶部点【启动引擎】
5. 去 **总览** 页看着它跑。模拟盘用的是**真实行情 + 虚拟资金**，和实盘唯一的区别就是钱是假的。

让它跑一两周。如果你能接受它每天的动作，再考虑实盘。

## 四、【重要】关于"接入同花顺账号"

我必须把话说清楚，免得你白折腾：

> **同花顺官方从来没有给散户提供下单 API。**

任何号称"直连同花顺账户"的方案，本质上都是这两种之一：

| 方案 | 原理 | 稳定性 | 门槛 |
|---|---|---|---|
| **A. easytrader（界面自动化）** | 程序模拟鼠标键盘去点你电脑上的同花顺下单窗口 | 一般，同花顺改版就可能失效；下单时会抢鼠标键盘 | 零门槛 |
| **B. 券商官方 API（QMT / PTrade 等）** | 券商给你的官方程序化交易接口 | 很稳，推荐 | 要找客户经理开通，通常有资金门槛 |

本平台**两个都支持**，但要实话告诉你：A 能用，但不适合长期无人值守；真要实盘，强烈建议走 B。

### 方案 A：同花顺通道（easytrader）配置步骤

**第 1 步** 装库。按 Win+R 输入 cmd 回车打开命令行，执行：

```
pip install easytrader
```

**第 2 步** 打开同花顺，进入【委托 / 下单】窗口，正常登录你的券商账号（普通交易权限就行）。

**第 3 步** 找到下单程序的路径 xiadan.exe：

* 按 Ctrl+Shift+Esc 打开任务管理器
* 找到 **「同花顺下单程序」** 这个进程 → 右键 → **打开文件所在位置**
* 地址栏右键 → 复制地址，一般长这样：`C:\同花顺软件\同花顺\xiadan.exe`

**第 4 步** 回到平台 **实盘交易** 页 → 找到「同花顺（easytrader）」卡片 → 把路径粘进输入框 → 点【切换到它】

**第 5 步** 连接成功后，页面上会出现 **实盘总开关**。这时你才需要认真考虑要不要开。

**注意事项：**

* 下单期间**不要动鼠标键盘**，程序在替你点。
* 同花顺要保持打开且已登录。
* 这台电脑的显示器最好别锁屏、别休眠。
* 程序重启、同花顺升级后，可能需要重新连接。
* 先点【环境自检】确认没有缺东西。

### 方案 B：QMT 通道（推荐，但要找券商）

1. 联系你的券商客户经理，说：**"我要申请 QMT / 量化交易权限"**
   （不同券商叫法不同：QMT、迅投、miniQMT、PTrade、量化交易终端）
   * 一般需要一定资金量，常见门槛 30~50 万，各家不同，有的可以谈
2. 装好 QMT 客户端，用资金账号登录，保持运行
3. 在平台 **实盘交易** 页的「QMT 迅投」卡片里填写：
   * userdata 目录（QMT 安装目录下的 `userdata_mini`）
   * 你的资金账号
4. 点【切换到它】

QMT 是券商官方 API，稳定、不抢鼠标、能程序化撤单查成交，**要做实盘就用这个**。

## 四之二、策略部署：一次授权，之后全自动

### 为什么要有这个

以前的逻辑有个大问题：**下单方式「待确认」是全局开关**，做不到「A 策略全自动、B 策略只出信号」；
而且策略只有 启用/停用，没有授权、没有资金分配、没有各自的止损。
结果就是你在实盘页一张一张点发送 —— **那叫手动交易，不叫量化。**

现在改成了真正的量化平台做法：**策略部署（一次性授权）**。

### 三步走

```
① 配策略        在【策略】页填好策略类型、参数、股票池，保存
② 配权重        在【持仓权重】区点【一键计算最优权重】或手动填，保存
③ 部署（确认）   点【部署 · 开始自动交易】，填风控参数 + 输确认口令
④ 全自动运行     引擎自动替它下单；【实盘交易】页变成只读监控面板
```

**确认发生在第 ③ 步，不是每一单。**

### 部署时要定的 7 件事

| 字段 | 说明 |
|---|---|
| **直接发送委托单** | 勾上 = 全自动直发；不勾 = 只生成待确认单，你逐笔把关 |
| **资金额度** | 这个策略最多能用总资产的百分之多少（不是全部资金都给它） |
| **单只股票上限** | 防止一只股票占太多 |
| **单笔委托上限** | 防止一笔下太猛 |
| **止损（必填）** | 不填不让部署 —— 自动交易没有止损等于风险敞口全开 |
| **止盈** | 0 表示不自动止盈 |
| **授权有效期** | 到期自动下线，强制你定期复核 |

### 部署时的四道闸门（不满足直接拒绝）

1. **全局风控被关掉** → 不給部署
2. **没填止损** → 不给部署
3. **实盘通道但总开关没开** → 不给部署
4. **确认口令打错** → 不给部署（全自动要输「我确认自动交易」，托管要输「我确认托管交易」）

### 部署之后在哪儿看

【实盘交易】页最上面新增 **「自动交易中的策略」** 面板：

| 列 | 看什么 |
|---|---|
| 模式 | 全自动直发 / 待你确认 |
| 状态 | 运行中 / 引擎未启动 / 已过期 |
| 资金额度 / 已用 | 给了多少、用了多少 |
| 止损 / 持仓 / 浮动盈亏 | 当前风险状况 |
| 今日动作 | 今天下了几单 |
| 授权到期 | 什么时候要重新确认 |

**这个面板是只读的 —— 你不需要在这里点任何东西。**

### 每只股票买多少：组合优化已和策略打通

策略页「股票池」下面有【持仓权重】区，填了股票池后会出现每只股票的权重输入框：

- **【一键计算最优权重】**：选方法（风险平价/最小方差/最大夏普/等权/因子加权）和因子组合，一键算出最优权重填进去
- **手动改**：直接在每个输入框里改你喜欢的比例
- **留空**：用策略默认分配

这套权重在**回测**和**实盘**里都生效 —— 回测页也会用到你设的权重。
所以你能先回测验证「这套权重历史表现如何」，再决定要不要部署。

### 三种托管程度，按熟练度递进

| 阶段 | 怎么设 | 你的动作 |
|---|---|---|
| 第 1-2 周 | 策略运行方式选「只看信号」 | 看它想做什么，不动钱 |
| 第 3-4 周 | 部署时**不勾**「直接发送」 | 每笔点发送或忽略 |
| 熟练后 | 部署时**勾上**「直接发送」 | 只监控 |

### 想停某个策略

【策略】页 → 找到它 → 点【下线】。引擎立刻不再为它下单。
**已持有的仓位不会被自动卖出** —— 那需要你自己决定。

## 四之三、实盘交易流程

打开 **实盘交易** 标签页，从上到下就是完整的实盘流程。

### 1. 实盘就绪检查（开实盘前逐条打勾）

页面顶部会自动列出 9 项检查，**打 ✘ 的关键项不过，就开不了实盘**：

| 检查项 | 关键? | 说明 |
|---|---|---|
| 交易通道已连接 | ✅ 关键 | 同花顺 / QMT 要连上 |
| 能读到账户资金 | ✅ 关键 | 连不上或读不到就不给开 |
| 风控已开启 | ✅ 关键 | 关掉风控非常危险 |
| **有止损保护** | ✅ 关键 | 要么设全局止损，要么用带止损的策略 |
| 账户有可用资金 | ✅ 关键 | 没钱发不出委托 |
| 至少启用一个策略 | — | 也可只手动下单 |
| 做过回测 | — | 提醒你先看历史表现 |
| 单笔上限设置合理 | — | 超过总资产一半会警告 |
| 下单方式 | — | 显示当前是待确认还是全自动 |

### 2. 待确认委托单（半自动下单，默认）

这是我最想让你用起来的功能。默认下单方式是 **「待确认」**：

```
策略出信号  ->  生成一张「待确认委托单」  ->  你在页面上点【发送】  ->  才真的发到券商
```

委托单表格里会显示：来源、代码、名称、方向、数量、**委托价**、**当前实时价**（带偏离%）、
信号理由、状态。价格跑掉多少一眼就能看到，不会稀里糊涂成交。

* 【发送】单张 ／ 【全部发送】批量（会弹确认框列出每一张）
* 【忽略】不要这张
* 委托单默认 **30 分钟过期**，过期自动失效，避免隔天用旧价格下单
* **发送前会重新跑一遍风控** —— 就算生成时通过了，发之前价格变了导致超限，一样会被拦下

想改成全自动：设置 → 交易规则 → 下单方式 → auto。

### 3. 持仓止损监控

每只持仓都算出**止损位**和**距止损百分比**：

止损位 = 「全局止损价」和「回调买入法技术支撑位」里**更紧的那个**（哪个先到算哪个）。

贴到止损位会提示「准备执行」，跌破了会红字警告「已经跌破止损位！」。
右边的【止损卖出】单只处理，顶上【一键全部止损】批量市价清仓（会弹确认框）。

### 4. 当日交易报告

成交笔数、买卖笔数、已实现盈亏、胜率、手续费合计、委托笔数，下面是当日成交明细。
**手续费那一栏别小看** —— 高频交易时它会吃掉你大部分利润。

### 5. 同花顺账号密码（可选，系统加密保存）

在「同花顺」通道卡片里可以填资金账号和交易密码。

**先说清楚：不填也能用。** 你只要自己把同花顺下单窗口打开、登录好，程序就能驱动它下单。
填了只是省掉手动登录这一步（程序会尝试帮你填登录框，叫 `prepare`，属尽力而为，不一定成功）。

**关于安全，我做了这些**：

* 密码用 **Windows 系统加密（DPAPI）** 保存 —— 用的是你这个 Windows 账号的密钥
* **只有同一台电脑、同一个 Windows 账号能解开**；别人把你的 data 目录整个拷走也解不开
* 接口**永远不会把密码返回给页面**，只返回「已设置 / 未设置」
* 日志里从不记录密码
* 如果你这台机器上系统加密用不了，**我会拒绝保存密码**，而不是退回明文存储
* 随时可以点【删除已保存密码】

数据库里实际长这样（可以自己去看 `data/quant.db` 的 kv 表）：

```
secret_ths_password = dpapi:AQAAANCMnd8BFdERjHoAwE/Cl+sBAAAA+rD/QdcF4EK2...
```

### 6. 从券商同步委托状态

【当日委托】旁边有【从券商同步状态】。同花顺/QMT 下的单会一直是「已报」，
点一下就能把「部成 / 已成 / 已撤 / 废单」和成交数量同步回来。

## 六之一、回调买入法（重点）

这是你点名要的策略，我把它做成了**一个因子 + 一个策略**。

### 核心思想

不是"买到最低点"，而是**"买在离止损最近的地方"**。

1. **强势**：先确认它在上升趋势里（价格站上 20 日线、20 日线在 60 日线上方、20 日涨幅达标）
2. **回调**：从近期高点回撤 1.5%~15%，**并且缩量**（缩量说明没人急着跑，是健康回调）
3. **贴近支撑**：现价离支撑位（20 日线 / 60 日线 / 近 10 日低点里最合适的那个）不超过 5%
4. **重启上涨**：收盘价突破前几天的最高价，并且是阳线
5. **止损**：放在支撑下方 2% 左右 —— 因为买点本来就贴着支撑，**所以止损特别近**

### 仓位自动算：这才是它最妙的地方

仓位 = **单笔风险预算 ÷ 止损距离**

假设你设单笔风险预算 1%（每笔最多亏总资产的 1%）：

| 股票 | 现价 | 止损 | 风险距离 | 自动算出的仓位 |
|---|---|---|---|---|
| A | 100 | 96 | 4% | 1% ÷ 4% = **25%** |
| B | 100 | 92 | 8% | 1% ÷ 8% = **12.5%** |

**止损越近，允许买的越多；止损越远，自动买得越少。**
这样不管买哪只，每笔亏掉的钱都是一样的。这就是"让买点尽量接近止损"的价值所在。

### 实测数据（12 只股票，2023-01 起，赔率 3:1 止盈）

```
收益 +13.99%   最大回撤 -5.34%   夏普 0.56   交易 95 笔   胜率 31.9%   盈利因子 1.88
```

**胜率只有 32%，但赚了钱** —— 这正是这个方法的特征：亏的时候亏得少，赚的时候赚得多。
如果你看到一个策略胜率 32% 就想放弃，那你永远做不了趋势交易。

### ⚠️ 一个反直觉的实测结果（值得你知道）

我把它做成因子丢进【因子实验室】跑扫描，结果是：

```
#4  买点到止损的距离(取负)    IC=+0.1223   t=+5.63   <- 好
#5  离支撑位的距离(取负)      IC=+0.1105   t=+5.88   <- 好
#6  回调买入评分              IC=-0.0985   t=-5.57   <- 反的！
```

**「离止损近」「离支撑近」很有用，但「回调买入评分」本身在这段时间是反着的。**

为什么？因为「评分高」= 一只强势股正在回踩支撑。如果那段时间大盘整体在跌，
这些"看起来完美"的回踩点会继续破位。而「离支撑近」这个信息单独看是正向的 ——
贴近支撑意味着下跌空间小、赔率高。

**这恰恰说明了这个方法的正确用法**：
它不是拿来横截面选股的（"哪只股票最好"），而是拿来**择时**的 ——
"我已经决定要买这只股票了，现在这个点位划不划算"。
用它当策略的买卖信号有效，用它当选股因子排名不一定有效。

别的地方不会告诉你这件事。

### 参数怎么调

* `take_profit_r` 止盈倍数：默认 3（赚到 3 倍止损距离就跑）
* `exit_on_ma_break` 跌破趋势均线卖出：默认开。关掉它能让盈利跑得更远，但回撤会变大
* `min_pullback` / `support_tol` / `max_risk`：想多做交易就放宽，想只做最好的机会就收紧

## 六之三、组合优化（新增）

选出股票只是第一步，**每只买多少钱**同样决定成败。打开 **组合优化** 标签页。

| 方法 | 逻辑 | 适合 |
|---|---|---|
| **等权分配** | 每只买一样多 | 基准，最难被打败 |
| **因子分加权** | 越看好买越多 | 进攻性强，但会集中押注 |
| **最小方差** | 让组合波动最小 | 熊市抗跌，牛市跑得慢 |
| **风险平价** | 让每只股票贡献的风险一样大 | **长期夏普通常最好，推荐** |
| **最大夏普** | 用因子分当预期收益，找最优风险收益比 | 理论最优，但对预期收益估计误差敏感 |

全部支持两个硬约束：**单只上限** 和 **总仓位上限**，只做多。

### 风险平价为什么好

它让低波动的股票拿更多权重、高波动的拿更少。你可以在结果页看到「风险贡献度」那张图 ——
**风险平价的目标就是让每根柱子一样高**（实测极差 0.000%）。

### 实测对比（8 只股票，2023-06 起，单只上限 15%）

```
等权       收益 +47.71%  回撤 -13.78%  夏普 0.84
因子加权   收益 +38.96%  回撤 -11.62%  夏普 0.81
风险平价   收益 +38.42%  回撤 -11.44%  夏普 0.80
最小方差   收益 +42.85%  回撤 -12.17%  夏普 0.86
最大夏普   收益 +47.09%  回撤 -11.84%  夏普 0.91   <- 夏普最高
```

**注意**：优化器在这些股票上主要降低了回撤，收益并没有更高。
这不是 bug —— 优化的目标是**风险调整后收益**，不是绝对收益。

> ⚠️ 如果你的股票数太少、或者单只上限设得太高（比如 5 只股票 × 上限 25% ≥ 总仓位 90%），
> 所有方法都会被上限压成差不多的等权。页面会直接用黄框提示你。

## 六之二、因子实验室（新增）

打开 **因子实验室** 标签页。这里解决一个问题：**到底哪个因子现在有用？**

### 什么是 IC
每天把股票池里所有股票按因子值排序，再按未来 N 日收益排序，两条排名序列的相关系数就是当天的 **IC**。
IC 长期为正，说明「因子值高 → 后面涨得多」。

经验参考：**|IC| > 0.03 有点用，> 0.05 算不错，> 0.1 很强但很少见。**

### 怎么用

1. 点 **开始扫描**（默认用内置的 40 只代表性股票，约 10~60 秒）
2. 排行榜会按 |IC| 排序，告诉你**当前**哪些因子最有效，以及每个因子的：
   * IC 均值、ICIR、t 值、IC>0 占比、多空收益、结论
3. 点某一行的 **详情**，看这个因子的：
   * IC 时间序列（哪天有效哪天失效）
   * 分层收益（第 1 组 = 因子分最高，单调下降才说明有区分度）
   * **今天的因子打分排名** —— 直接告诉你现在哪些股票因子分最高
4. 点 **建策略**，会自动把该因子填进「单因子择时」策略表单

### 行业中性化（新增，建议开启）

勾上【行业中性化】后，同行业的股票之间互相比较，只留下"行业内相对强弱"。

**为什么有用**：如果整个白酒板块都在涨，那所有白酒股的动量因子分都会很高 —— 这是"行业 beta"，
不是选股能力。中性化之后，你选出来的是**行业里真正最强的那只**。

实测（20 只股票，低换手因子）：IC 从 **+0.1158 提升到 +0.1291**，t 值从 4.45 到 4.78。

实现方式：同一天、同一行业里，把因子值减去行业均值。行业里不足 3 只股票就不动它，避免把噪音当信号。

* 我在你机器上实测（2026-10，16 只股票 200 天）时，**低波动、低换手**这一类因子排在前面，
  IC 能到 0.15~0.22，t 值 6 以上。这反映的是**那一段时间的市场风格**，不是永恒规律。
* 因子会**拥挤**：所有人都用同一个因子时，它就失效了。
* 小样本（股票少于 20 只）算出来的 IC 噪声很大，别当真。
* 先用模拟盘，别拿这个当理由上实盘。

## 七、常见问题

**Q：要花钱吗？**
A：平台本身不要钱，行情数据是免费公开接口。交易时券商正常收佣金印花税。

**Q：数据准吗？**
A：行情来自东方财富，另有腾讯、新浪做备份，和你看盘软件的数字基本一致。但免费接口偶尔会抽风，平台会自动切换数据源。

**Q：能自动交易吗？**
A：能。策略设成「自动下单」+ 引擎启动 + 打开实盘开关，就会自动买卖。但强烈建议先在模拟盘跑通。

**Q：程序关了就停了吗？**
A：是的。关掉黑窗口，引擎和网页都停了，不会再有任何新委托。已经挂到券商那里的委托还在，要自己在券商软件里撤。

**Q：为什么回测一笔都没成交？**
A：多半是**股价太高、资金不够买一手**。A 股买一次最少 100 股，贵州茅台 100 股就要十几万。回测结果里会直接用黄色框告诉你原因。

**Q：同花顺连不上怎么办？**
A：按顺序检查：① 装了吗 pip install easytrader；② 同花顺下单窗口开了吗、登录了吗；③ 路径指向的是 xiadan.exe 吗；④ 点【环境自检】看提示。它有时候就是会被同花顺改版弄挂，这不是你的问题。

**Q：端口 8899 被占用？**
A：平台会自动往后找可用端口，看黑窗口里打印的实际地址。

**Q：我的数据在哪？**
A：全在 `data\` 目录。quant.db 是数据库（策略、成交、日志），settings.json 是设置，stock_list.json 是股票缓存。想彻底重来就删掉 data 文件夹。

## 九、风险提示（请认真读）

1. **量化交易不保证盈利。** 历史回测表现好，不代表未来赚钱。大部分策略长期跑不赢指数。
2. **自动化交易会放大错误。** 程序 bug、参数设错、接口异常，都可能在很短时间内造成实际亏损。
3. **同花顺通道有天然缺陷。** 界面自动化可能点错、可能失效、可能重复下单。请小仓位试。
4. **网络和第三方接口都有风险。** 免费行情接口可能延迟、中断，不要拿它做高频交易。
5. **本程序按"现状"提供**，作者不对任何交易结果负责。**请只用你亏得起的钱。**
6. A 股有涨跌停和 T+1 限制，急停清仓在跌停板上可能清不掉。

**先用模拟盘。真的。**

## 十、开发与测试

### 环境要求

* **Python 3.9+**，只用标准库，没有任何 `pip install`
* Windows（启动脚本是 `.bat`；核心代码跨平台，Mac/Linux 可以 `python -m app.main` 直接跑）

### 跑测试

压测脚本都是独立可执行的，不需要 pytest。默认**不碰你的真实数据库**
（`stress_test_fee.py` 自己建临时库），只有加 `--live` 才会联网：

```bash
python tools/stress_test_fee.py          # 手续费记账 40 项
python tools/stress_test_grid.py         # 择时网格 36 项（--live 再加 6 项联网）
python tools/stress_test_fundamental.py  # 基本面模块 38 项
python tools/stress_test_rank.py --live  # 排行数据源 62 项（需要网络）
```

### 改代码前值得先看的约定

* **文档是生成的**：`学习手册.md` / `操作手册.md` / `CHANGELOG.md` 由
  `python tools/make_docs.py` 从代码生成。直接改 md 会被覆盖，要改内容请改生成器
  `tools/make_docs.py` 和模板 `tools/manual_template.md`。
* **版本号只有一处**：`app/__init__.py` 的 `__version__`，启动脚本和 server 都动态读取。
* **因子注册**：`factors.py` 里用 `@register(key, name, family, desc, direction, params)`。
* **策略注册**：`strategies.py` 里用 `@register` 类装饰器，组合类策略设 `portfolio = True`。
* **调仓日判断**：必须用 `day_no(date) % reb`（日历日序号），不能用数组下标——
  数据缺失时下标会漂移，导致信号横跳、反复买卖。
* **数据目录不入库**：`data/`、`logs/`、`股票组合/` 都在 `.gitignore` 里。
